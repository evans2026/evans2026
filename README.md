## What's here

**[baa-commission-engine](https://github.com/evans2026/baa-commission-engine)** — Proof-of-concept for long-tail profit commission calculation under binding authority agreements in specialty insurance. Pluggable scheme architecture, four temporal dimensions, sliding scale band-crossing, carrier split persistence, clawback floor guards, and full audit reproducibility. Python, PostgreSQL, Docker.

**[smartterr](https://github.com/evans2026/smartterr)** — IoT environmental monitoring system built on a Raspberry Pi Pico WH. 15+ sensors, MicroPython edge layer, Flask aggregator, React dashboard. Rolling Z-score anomaly detection, regression-based depletion forecasting, and automated heating/ventilation control — all running on a microcontroller.

**[pico-data-pipeline](https://github.com/evans2026/pico-data-pipeline)** — End-to-end sensor data pipeline: hardware → MQTT → ingestion → validation → transformation → anomaly flagging → live Plotly Dash dashboard. Immutable raw layer, enriched clean layer, full backfill support.
